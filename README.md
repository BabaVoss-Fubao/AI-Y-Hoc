# Từ hỏi AI đến giao việc cho AI

Bài trình bày của **ThS.BS Nguyễn Văn Tú**. Trang web trình chiếu, chạy được trên GitHub Pages hoặc mở thẳng file `index.html` trên máy (không cần mạng).

## Phím tắt khi trình chiếu
- Mũi tên phải / Space: trang sau. Mũi tên trái: trang trước.
- **S**: mở cửa sổ ghi chú người nói (kịch bản, đồng hồ, trang kế tiếp). Kéo cửa sổ này sang màn hình laptop, để màn hình chính cho máy chiếu.
- **F**: toàn màn hình. **Esc** hoặc **O**: xem tổng quan các trang. **B**: tạm tắt màn hình đen.
